# Open Gym Analytics

## Objetivo

Analizar patrones de uso de espacios deportivos comunitarios para identificar actividades más populares, horarios de mayor demanda y comportamiento de usuarios.

## Herramientas utilizadas

* Power BI
* Power Query
* Excel

## Proceso realizado

* Limpieza y transformación de datos
* Tratamiento de valores faltantes
* Creación de métricas y KPIs
* Desarrollo de dashboard interactivo
* Análisis exploratorio de datos

## KPIs principales

* Total de asistentes
* Actividades más populares
* Centros comunitarios más utilizados
* Horarios pico

## Insights encontrados

* Open Gym y Basketball presentan mayor demanda.
* Las horas de mayor actividad se concentran entre las 10 AM y 3 PM.
* Algunos centros comunitarios presentan significativamente más asistencia que otros.
